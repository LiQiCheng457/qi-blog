# 水豚祁的下班计划：资源设定

## 1. 视觉与交付规范

首版为横向 2.5D 场景。整体使用温暖、轻松、略带日系生活感的 2D 插画风格；避免写实 3D、过度复杂的透视和高密度 UI。资源应支持网页叠层、昼夜变化和移动端缩放。

| 项目 | 建议规格 |
| --- | --- |
| 主场景画布 | 1920 x 1080 px，横向 16:9 |
| 安全交互区 | 画面中间 80% 宽度，避免关键物件贴边 |
| 静态场景 | WebP；需要透明通道的叠层使用 PNG 或 WebP alpha |
| 角色循环动画 | 优先透明 WebP 动图；单帧静态备份 PNG |
| UI 图标 | SVG 或统一线性 PNG |
| 音效 | OGG 或 MP3，短音效控制在 1 至 3 秒 |
| 命名规则 | `room-day-base.webp`、`qi-typing.webp`、`fx-rain-01.webp` |

所有可交互物件需提供透明热区尺寸或在资源表中标注其在 1920 x 1080 坐标系中的边界，便于前端使用绝对定位创建点击区域。

## 2. 主场景分层

不要将房间交付为不可拆分的一张图片。场景需要至少拆为以下层，前端按顺序叠加：

| 层级 | 资源 | 用途 |
| --- | --- | --- |
| 01 背景 | 墙面、地板、远景窗外 | 昼夜和天气版本的基础画面 |
| 02 固定家具 | 书桌、床、沙发、冰箱、书架、门 | 主要室内结构 |
| 03 可变家具 | 电脑屏幕、冰箱门、游戏机屏幕、书架收藏 | 根据交互或解锁状态替换 |
| 04 角色 | 水豚祁各状态动画 | 固定行为点位显示 |
| 05 前景 | 窗帘、地毯边缘、桌面小物 | 提供空间层次，可覆盖角色局部 |
| 06 氛围特效 | 雨滴、阳光、屏幕光、夜间光晕 | 根据时间、天气、事件动态开关 |
| 07 UI | 状态栏、行动菜单、事件弹窗 | 独立于场景实现 |

### 场景版本

- `room-morning-base`：晨光、浅蓝窗外、台灯关闭。
- `room-afternoon-base`：自然光稳定，适合常规交互。
- `room-evening-base`：暖橙晚霞，窗外和地板具有长阴影。
- `room-night-base`：深蓝窗外、台灯或电脑屏幕成为主要光源。
- `room-weather-rain`：透明雨滴和阴天窗景覆盖层。
- `room-weather-storm`：较暗窗景、远处闪电叠层，低频使用。

## 3. 房间物件资源

| 物件 | 必需状态 | 建议交互反馈 |
| --- | --- | --- |
| 书桌与电脑 | 普通、屏幕亮、屏幕报错、屏幕完成 | 屏幕闪烁、通知弹出、键盘微光 |
| 沙发 | 普通、被压下、毯子展开 | 轻微下陷、耳机或音乐符号 |
| 冰箱 | 关闭、打开、空、装有水果 | 开门光线、水果获得特效 |
| 游戏机 | 关闭、运行、胜利/失败画面 | 屏幕闪光、像素粒子 |
| 床 | 整洁、午睡中、夜间睡眠中 | 被子轻微起伏、睡眠气泡 |
| 窗户 | 晴、雨、晚霞、夜景 | 雨滴、光线、偶发闪电 |
| 门口 | 关闭、门缝亮、包裹出现 | 门铃、包裹弹跳、人物影子 |
| 书架 | 基础、局部收藏解锁、满收藏 | 新物品发光、便签掉落 |

交互高亮无需重绘完整物件：优先使用半透明描边、柔和发光或轻微上下浮动的 CSS 效果。只有冰箱门、电脑屏幕、门和游戏机屏幕等真正会改变形态的物件需要独立状态图。

## 4. 水豚祁角色资源

角色需要统一基准高度和锚点。建议设计高度约为 360 至 460 px，锚点在脚底中点；每张图保留透明安全边距，避免 CSS 缩放时裁切。

| 资源名 | 行为点位 | 最低帧数或形式 | 内容说明 |
| --- | --- | --- | --- |
| `qi-idle` | 房间中央 | 静态 PNG + CSS | 呼吸、眨眼、轻微摇摆 |
| `qi-typing` | 书桌 | 4 至 8 帧循环 | 手部打字、屏幕反光 |
| `qi-tired` | 中央或书桌 | 3 至 5 帧循环 | 打哈欠、低头、放空 |
| `qi-sleeping` | 床或沙发 | 4 至 6 帧循环 | 呼吸、被子起伏、睡眠气泡 |
| `qi-eating` | 冰箱或沙发 | 4 至 6 帧循环 | 吃水果、满足表情 |
| `qi-gaming` | 游戏机 | 4 至 8 帧循环 | 手柄操作、投入或失落 |
| `qi-surprised` | 书桌或门口 | 1 次短动画 | 后仰、感叹号或震动 |
| `qi-happy` | 中央或沙发 | 1 次短动画 | 小跳动、星星或闪光 |
| `qi-overwhelmed` | 书桌 | 4 至 6 帧循环 | 趴桌、代码符号飘出 |

首版可使用静态角色图结合 CSS 完成 `idle`、`tired` 和 `happy`，把动图资源优先投入 `typing`、`sleeping`、`eating`、`gaming` 四个高频行为。

## 5. 特效与动效资源

| 分类 | 资源 | 实现建议 |
| --- | --- | --- |
| 环境 | 雨滴、阳光粒子、晚霞光、闪电 | CSS 或低帧率透明 WebP 叠层 |
| 情绪 | 感叹号、问号、汗滴、爱心、睡眠气泡 | SVG/PNG 图标 + CSS 弹出动画 |
| 行动 | 键盘字符、屏幕通知、食物星光、游戏像素 | CSS 小粒子或透明 PNG 序列 |
| 获得 | 收藏卡片、新物品光圈、成就印章 | UI 动画，时长控制在 600 ms 内 |
| 转场 | 昼夜渐变、事件弹窗、日结算 | CSS opacity/transform，避免全屏重特效 |

动画时长建议：悬停 150 至 200 ms，物件行动反馈 300 至 600 ms，角色短表演 800 至 1,500 ms，循环动画 1.5 至 3 秒。所有循环动画都要有静态降级资源，以兼顾低性能设备和“减少动态效果”系统设置。

## 6. UI 资源与布局

UI 保持像“房间中的轻量游戏面板”，不要遮挡主要场景。

| 模块 | 内容 | 资源需求 |
| --- | --- | --- |
| 顶部状态栏 | 时间、精力、心情、压力 | 四个图标、状态条、昼夜指示 |
| 待办抽屉 | 当前任务与完成标记 | 任务图标、完成印章 |
| 物件行动菜单 | 点击物件后的 2 至 4 个选项 | 小图标、按钮背景、消耗提示 |
| 事件弹窗 | 事件插画、文字、选项 | 小型事件插图框和选择按钮 |
| 日结算 | 今日故事、奖励、结局 | 日记纸张/卡片、结局徽章 |
| 收藏页 | 水果、装饰、服装、故事 | 分类图标、锁定态、获得态 |
| 设置 | 音乐、音效、动态效果、重开 | 通用图标 |

移动端应将顶部状态栏压缩为图标与数值；待办和收藏使用底部抽屉；点击热区最小尺寸不低于 44 x 44 CSS px。

## 7. 音频资源

首版可从少量高辨识度素材开始：

| 类型 | 数量 | 内容 |
| --- | --- | --- |
| 背景音乐 | 3 首 | 白天轻松、傍晚温暖、夜晚安静 |
| 环境音 | 3 组 | 晴天微风、下雨、夜晚室内 |
| 交互音效 | 10 至 15 个 | 点击、键盘、开冰箱、吃水果、开门、游戏机、收获、成就 |
| 角色音效 | 5 至 8 个 | 打哈欠、惊讶、开心、困倦、睡着 |

背景音乐在时间阶段切换时采用 500 至 1,000 ms 的淡入淡出。默认提供独立的音乐、音效和动态效果开关。

## 8. 前端落地映射

资源目录建议如下：

```text
frontend/public/games/qi-after-work/
  room/
  props/
  characters/
  effects/
  ui/
  audio/
```

场景在 Vue 中由绝对定位层组成；每个物件由 `id`、热区坐标、可用行动和视觉状态描述。游戏状态由 Pinia 或一个 composable 管理，存档初期写入 localStorage。角色只在预定义锚点间切换，前端根据 `characterState` 渲染动画资源，不实现自由寻路或碰撞系统。

## 9. 首版制作优先级

1. 下午版主场景、八个物件普通态、角色待机图、基础 UI。
2. 电脑、床、冰箱、游戏机的使用中状态；打字、睡觉、吃水果、游戏四组角色动画。
3. 早晨/傍晚/夜晚场景差分、晴天与雨天特效、行动和事件弹窗。
4. 收藏品、装饰变化、日结算、音频和隐藏事件专属特效。

在资源不足时，优先保证角色表情、昼夜氛围和四个高频互动物件；这些内容最直接决定 IP 感和游戏反馈。
