# 水豚祁的下班计划：主题设定

## 1. 项目定位

《水豚祁的下班计划》是一款围绕水豚祁 IP 制作的轻叙事生活模拟游戏。玩家并非追求战斗、数值养成或高难操作，而是在一天的有限时间里，帮助水豚祁在工作、休息、兴趣和突发安排之间作出选择。

游戏的核心感受是：日常有一点混乱，但可以慢一点；事情不一定全做完，睡觉和水果也很重要。

首版采用单房间 2.5D 点击交互形式。水豚祁不需要自由移动，角色会根据玩家选择切换到固定行为点位并播放相应动画。

## 2. IP 与叙事语气

水豚祁是一个想睡觉、喜欢水果、会写代码也会被突然安排吓到的陪伴型角色。他认真但不紧绷，偶尔吐槽，面对麻烦时会先说一句“好麻烦”，然后还是去处理。

叙事应遵循以下原则：

- 温和、轻松、带一点无奈的冷幽默。
- 不把效率、加班或任务全清作为唯一成功标准。
- 所有失败结果都应成为有趣的小故事，而非惩罚。
- 避免高压倒计时、战斗和挫败性数值惩罚。
- 角色的偏好应自然进入玩法：睡觉、水果、游戏、听音乐、写代码和看窗外。

## 3. 玩家目标与玩法循环

玩家从早晨开始安排水豚祁的一天。房间中的家具和物件分别提供行动，行动会消耗时间，并改变精力、心情和压力。工作待办、天气和随机事件让每次流程产生差异。

```text
开始新的一天
  -> 查看待办、天气与角色状态
  -> 点击房间物件选择行动
  -> 时间推进，状态与房间反馈变化
  -> 处理随机事件并作出分支选择
  -> 到达夜晚，结算任务、收藏与当天故事
  -> 解锁结局、成就或房间装饰
```

每一局建议控制在 10 至 20 分钟；玩家可以随时存档，也可以在结算后开始新的一天，探索不同选择。

## 4. 核心状态

首版只保留四项易理解的状态，数值建议使用 0 至 100：

| 状态 | 含义 | 低值或高值反馈 |
| --- | --- | --- |
| 精力 | 行动能力和工作效率 | 过低时会打哈欠、行动收益降低，可能直接睡着 |
| 心情 | 当天的主观状态 | 过低时吐槽增多，较难获得好结局 |
| 压力 | 被任务和安排堆积的程度 | 过高时触发趴桌、脑袋宕机或逃避事件 |
| 时间 | 从早晨到深夜的推进 | 决定可完成行动数、事件和日结局 |

待办不是强制清单。完成待办会增加结算评价和解锁内容，但休息、探索或触发特殊剧情同样具有价值。

## 5. 房间与交互

首版场景是水豚祁的房间，采用横向固定镜头。环境随早晨、傍晚、夜晚和天气变化，物件状态也可随事件改变。

| 交互物件 | 可选行动 | 主要影响 | 代表事件 |
| --- | --- | --- | --- |
| 书桌与电脑 | 修 Bug、写点东西、处理消息、关机 | 推进待办，增加压力或成就感 | 临时需求、灵感、代码报错 |
| 沙发 | 休息、听歌、发呆 | 恢复心情，降低压力 | 不小心睡着、喜欢的歌循环播放 |
| 冰箱 | 吃水果、喝水、点外卖 | 恢复精力或心情 | 冰箱空了、外卖迟到 |
| 游戏机 | 玩一局、查看收藏 | 心情显著上升，消耗时间 | 连败、意外破纪录 |
| 床 | 午睡、提前睡觉 | 大量恢复精力，跳过时间 | 睡过头、夜间灵感 |
| 窗户 | 看天气、听雨、放空 | 降低压力，获得氛围剧情 | 晚霞、暴雨、彩虹 |
| 门口 | 收快递、接待、外出 | 获取物品或触发安排 | 临时会议、朋友邀约 |
| 书架 | 阅读、查看收藏、整理 | 解锁设定、装饰或故事片段 | 发现旧照片、掉出便签 |

点击物件后显示 2 至 4 项行动。行动确认后，角色移动到预设点位，场景播放反馈动画，再结算时间和数值。

## 6. 时间结构

一天分为四个阶段：早晨、下午、傍晚、夜晚。每次行动消耗 30 分钟、1 小时或 2 小时；阶段变化时更新光照、背景音乐、可触发事件和物件行动。

| 阶段 | 氛围 | 侧重内容 |
| --- | --- | --- |
| 早晨 | 明亮、安静、略困 | 规划、早餐、首个待办 |
| 下午 | 常规工作节奏 | 工作事件、快递、游戏短休息 |
| 傍晚 | 暖色光线和收尾感 | 晚霞、外卖、朋友邀约 |
| 夜晚 | 台灯、窗外深蓝 | 夜间灵感、提前睡觉、日结算 |

## 7. 事件与分支

事件分为日常、工作和隐藏三类。每个事件给出 2 至 3 个选择，并明确显示或通过叙事暗示其时间和状态代价。

示例：

```text
事件：临时需求在傍晚发来了。

A. 现在处理：待办 +1，压力 +20，时间 -2 小时。
B. 先吃点水果：精力 +10，心情 +15，时间 -1 小时，随后仍需决定是否处理。
C. 假装没看见：压力 -5，留下未读消息，夜晚可能触发后续事件。
```

隐藏事件由玩家行为组合触发，例如连续三次玩游戏、连续拒绝安排、夜晚多次看窗、冰箱为空或连续高压工作。隐藏事件要提供角色特性和小惊喜，而非单纯稀有奖励。

## 8. 结局与长期目标

日结算应从任务、状态、事件和收藏四方面总结当天，并记录一段简短的日记式文本。建议首版提供以下五种结局：

| 结局 | 达成倾向 |
| --- | --- |
| 准点下班 | 适量完成任务，压力可控，在夜晚前休息 |
| Bug 修好了，晚饭错过了 | 高工作投入，精力或心情偏低 |
| 今天谁也别想打扰我睡觉 | 多次拒绝安排或大量休息 |
| 游戏打得不怎么样，但心情很好 | 多次使用游戏机或沙发，任务完成较少 |
| 夜晚的灵感 | 夜晚仍有精力，在电脑或书架触发特殊事件 |

长期目标包括收集水果、房间装饰、角色服装、故事片段和成就。它们可改变房间视觉、增加可选行动或解锁小剧情，但不应破坏轻度体验。

## 9. 首版范围

- 一个可切换昼夜和天气的房间。
- 八个可点击物件。
- 四项状态、五条基础待办。
- 15 至 20 个随机事件，至少 5 个隐藏事件。
- 八类角色行为状态。
- 五个日结局和基础收藏页。
- 使用 localStorage 保存当前日进度、收藏和已解锁内容。

后续可加入跨设备存档、更多房间、限定事件日历，以及由 AI 助手根据当天经历生成一句角色化总结。
