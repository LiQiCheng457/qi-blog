> 版本：v3.0（2026-10-12）
> 适用范围：「下班后·水豚祁的房间」小游戏全部场景资产

## 0. 一句话定位

**水豚下班后，回到河畔自己的巢。**
这是"自然材质的家"，不是野外；是"水豚的巢借用人的生活方式"，不是"人的房间住着一只水豚"。

## 2. 世界观与叙事锚点

- **居民**：水豚祁，21 岁，数据科学专业应届生。下班/下课回巢，发呆、吃瓜、听歌、偶尔看两眼代码。
- **时间**：默认下午到黄昏（day）；状态切换：rain（雨天）、night（夜晚）。
- **材质观**：一切家具都是自然材料的手作物——藤编、陶土、原木、干草、苔藓、鹅卵石。允许轻微使用痕迹（磨圆的边角、补丁、水渍），**禁止**工业感、金属光泽、塑料感。
- **形状观**：圆润、无锐角、矮胖比例。水豚的世界里没有直线家具。

## 4. 光影

- **唯一光源**：左上方藤窗透入的暖金色午后阳光
- 所有物件：**左上受光、右下背光**，过渡柔和（水彩晕染，不要喷枪高光）
- **接地阴影由引擎统一绘制**（RoomScene.vue 的 CSS drop-shadow），资产侧规则：
  - 不要在图里画投影、不要画地面、不要画地垫
  - 物件与地面接触的底边必须是**平的、干净裁切**
- 集成时引擎阴影参数加深一档（`0 5px 4px → 0 7px 6px, opacity .12 → .18`），由代码完成，与资产无关

---

## 5. 视角与地平线

- 正视、微俯约 5°，与 V2 底图一致
- 所有物件共用同一条视平线；**禁止** 3/4 视角、仰视、俯视
- 物件图形的最低点必须落在图片底边 5% 以内（引擎按图片底边对齐 floor 线）

## 7. 工艺与交付规范

1. **格式**：透明 PNG；绿幕生成后必须去边（defringe）——收缩 alpha 1px 并清除边缘色染，V2 沙发/床/角色上的黄红毛边是反面教材
2. **分辨率**：物件长边 ≥ 800px（画布上最大物件约 530px 宽，留 1.5 倍余量）
3. **状态一致性**：同一物件多个状态（如 sofa 的 idle/rest/music）必须同底稿改细节：轮廓、视角、大小完全一致，只变状态内容
4. **平底**：物件图片底边 = 与地面的接触线，不要把场景地面、垫子、影子画进图里
5. **命名与目录**：严格按 `v3/asset-manifest.json`（随第一批资产落地）

## 10. 验收清单（每张图逐条打勾）

**风格五条**
- [ ] 色板：能在第 3 节色表中找到所有主色，饱和度不高于底图植被
- [ ] 技法：水彩+彩铅纸面质感，无喷枪高光、无塑料感、无黑描边
- [ ] 视角：正视微俯 5°，与其他物件同视平线
- [ ] 光源：左上受光、右下背光
- [ ] 材质：自然材料手作感，圆润无锐角

**工艺三条**
- [ ] alpha 干净：浅色背景上无黄/红毛边
- [ ] 平底无自带影/地面/地垫
- [ ] 尺寸符合第 6 节比例表（±10% 以内）

**一致性一条**
- [ ] 同物件多状态：轮廓/视角/大小完全一致
