# 游戏界面插图 / Game UI Illustrations

## 生图提示词

请参考提供的水豚祁基图与房间基图，设计一组用于温暖 2D 网页生活模拟游戏的轻量 UI 插图和图标。图标不出现角色，但必须延续细腻棕色手绘线、圆润边缘、淡纸张纹理、低饱和奶油黄、蜜桃粉、鼠尾草绿和浅木棕配色；简洁清晰，在 24px、32px、48px 下均可识别。透明背景、无文字，分别制作：精力的小闪电或热饮、心情的温和笑脸、压力的小云、时间的简约时钟、待办便签、存档小盒子、设置齿轮、音乐音符、音效喇叭、动态效果小闪光；另制作一张空白日记风日结算卡片、小型成就徽章底座、锁定收藏剪影、已获得收藏光圈。不要玻璃拟态、霓虹、强渐变、纯黑描边、商业 SaaS 图标风、真实品牌或水印。
