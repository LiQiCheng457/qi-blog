# 互动家具状态 / Interactive Furniture

## 生图提示词

请参考提供的水豚祁基图与已确认的房间基图，制作一套透明背景的 2D 互动家具状态资源。所有家具必须完全匹配房间基图中的视角、尺寸、锚点、光源、棕色线稿粗细、木材纹理、阴影方向，以及奶油黄、蜜桃粉、鼠尾草绿、浅木棕的低饱和色板；每套状态只改变交互部位，底座尺寸和位置绝不能变化。分别输出：木质书桌与电脑的普通、屏幕亮起、报错、完成状态；浅色冰箱的关闭、打开、空、装满水果状态；复古游戏机的关闭、运行、胜利、失败状态；入口门的关闭、门缝透光、快递包裹出现状态；书架的基础、部分收藏解锁、满收藏状态。边缘清晰、便于网页叠加替换；不要人物、房间背景、文字、真实品牌、界面或水印。
