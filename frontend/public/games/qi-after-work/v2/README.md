# 水豚祁下班后房间 v2 资源说明

这是为“背景层 + 可交互物件层 + 角色层 + UI 层”准备的新资源包。它与当前正在使用的资源完全隔离，图片生成和验收完成后，再由代码切换到这套资源，避免影响现有页面。

## 画布与文件规范

- 房间基础场景：`2048x1152` PNG，16:9 比例。
- 可交互物件：透明 PNG，建议先以 `1024x1024` 生成，再裁切到物件四周保留约 12% 留白。
- 角色动作帧：透明 PNG，`512x512`。
- 特效：透明 PNG，`512x512`。
- 菜单、气泡、文字与按键：继续由 Vue 和 CSS 绘制，不生成带文字的 UI 图片。
- 文件名必须与 `asset-manifest.json` 一致，使用英文小写和连字符。

## 目录职责

```text
v2/
  base/                 房间建筑基础层
  objects/              独立可交互物件及其状态
    fridge/             冰箱
    desk/               书桌与电脑
    console/            游戏机
    door/               门与包裹
    bookshelf/          书架
    sofa/               沙发
    bed/                床
    window/             窗外天气与昼夜覆盖层
  characters/           水豚祁的动作帧
  effects/              爱心、雨滴、睡意等短暂特效
  ui/                   预留给非文字装饰性 UI 素材
  references/           放入已确认的风格参考图，不供页面直接加载
```

## 图层顺序

1. `base/`：墙面、地板、窗洞、门框、踢脚线等永久建筑，不含可移动家具。
2. `objects/`：冰箱、沙发、书桌、书架、床等；状态变化时替换这里的图片。
3. `characters/`：水豚祁，锚点固定在脚底。
4. `effects/`：交互瞬间显示的短暂特效。
5. Vue/CSS：热点、状态气泡、对话、导航与面板。

## 生成顺序

先生成并确认 `base/room-day.png`，随后只生成冰箱和书桌的各一张状态图，放进页面检查透视、尺寸、落地位置和光线。确认无误后，再生成其余物件及状态变体。

完整中文生图提示词见 `generation-prompts.md`；所需文件名和状态清单见 `asset-manifest.json`。
