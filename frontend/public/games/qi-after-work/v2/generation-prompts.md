# 水豚祁下班后房间 v2 中文生图提示词

当前的 `room/Room_Base.png` 只能作为**画风、色彩和构图参考图**。不要要求模型从中抠出家具；正确顺序是先生成基础场景，再按该场景生成每个独立物件。

## 全部图片共用的画风约束

每一条提示词末尾都追加以下内容：

```text
温暖手绘二维治愈系游戏插画，淡淡的水彩与彩铅纸张纹理，物体轮廓清晰易读。左侧窗户投进柔和的金色午后阳光，奶油色墙面、蜂蜜色木地板、橄榄绿和蜜桃色点缀。固定为平视、略带正面的室内横向视角。与参考房间保持相近的配色、线条粗细、光源方向和安静温馨的居住氛围。不要文字、商标、水印、UI、人物或动物，除非提示词明确要求。
```

每一张“可交互物件”图片末尾都再追加以下内容：

```text
请把单个游戏物件放在纯色 #00ff00 绿幕背景上，方便后续抠成透明 PNG。物件四周保留约 12% 空白，物件必须完整可见。不要地面、不要房间背景、不要投影、不要接触阴影、不要反光、不要文字、不要水印。所有状态图必须保持相同的平视角度、物件轮廓比例和左侧来光方向。
```

生成后需将绿幕去除，保存为透明 PNG，并严格按 `asset-manifest.json` 中的目录和文件名放置。每个状态单独生成一张图片，不要把多个状态拼在同一张图中。

## 4. 水豚祁与特效

先生成 `characters/qi-idle.png` 并确认体型比例；后续角色动作必须把这张图作为视觉参考，以保持脚底锚点、毛色、脸部与身体比例一致。

角色提示词：

```text
用途：二维游戏独立角色动作帧。
主要求：名为“祁”的可爱小水豚伙伴，暖棕色毛发，圆滚身体，小爪子，柔和腮红，安静友好的表情，适合温馨室内游戏。当前姿势为：[替换为下方对应动作]。
```

- `qi-idle.png`：正面放松站立。
- `qi-walk-1.png`、`qi-walk-2.png`：两张连续走路姿势，左右脚交替。
- `qi-typing.png`：坐在小键盘前，专注打字。
- `qi-sleeping.png`：蜷在小奶油色毯子下休息。

特效同样使用绿幕物件约束，分别生成一个主体：小爱心、雨滴、暖色闪光、没有字母的睡意云、问号、汗滴。保存路径和文件名以 `asset-manifest.json` 为准。

## 验收清单

- 基础层不包含任何可移动家具。
- 每种状态图的轮廓、透视和落地位置一致。
- 放进页面后，家具底部处在同一条地面基准线上。
- 透明 PNG 没有绿色边缘、实色背景或多余阴影。
- 所有图片没有文字、水印、商标或烘焙进图片的 UI。
- 在批量生成前，先把冰箱和书桌的两种状态放进页面实测。
