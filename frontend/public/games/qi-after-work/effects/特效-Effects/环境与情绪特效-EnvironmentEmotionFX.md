# 环境与情绪特效 / Environment and Emotion Effects

## 生图提示词

请参考提供的水豚祁基图与房间基图，制作一组透明背景的 2D 网页生活模拟游戏特效素材。全部采用轻薄圆润、低饱和的棕色手绘笔触与柔和纸张质感，像基图中的小星光、云朵、雨滴和灯光；特效只是细小反馈，不遮挡角色和场景。分别单独输出：细密雨滴前景层、窗边阳光尘埃粒子、一次短促遥远闪电、电脑屏幕淡蓝光晕、睡眠气泡、感叹号、问号、小汗滴、小爱心、获得物品时的暖金色小星光、复古游戏像素粒子。每项背景全透明，轮廓清晰，适合 CSS 动画、循环 WebP 或 PNG 叠层。不要人物、家具、文字、品牌、水印、锐利矢量风、浓烈霓虹、真实粒子或厚重发光。
