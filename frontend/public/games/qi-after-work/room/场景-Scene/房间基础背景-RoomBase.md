# 房间基础背景 / Room Base

## 生图提示词

生成前请提供水豚祁基图作为整体画风参考。画面统一使用细腻棕色手绘线稿、柔和纸张纹理、圆润物体边缘、低饱和奶油黄、蜜桃粉、鼠尾草绿和浅木棕配色，以及从左上方进入的温暖漫射光。横向 2D 网页游戏场景，1920x1080，16:9，固定侧视偏正面的 2.5D 单间公寓；镜头、透视、物体位置与光源在后续所有资源中保持不变。

### 远景

房间左侧大窗户外的安静晴天景色：浅奶油蓝天空、几朵圆润白云、远处模糊的树冠和低矮建筑轮廓，柔和晨午间自然光从窗外斜照进入。窗外景色只作为远景，不抢占室内画面，不出现人物、文字、招牌、车辆或真实城市细节。

### 中景

横向单间公寓室内主体，所有关键家具完整可见并保持清晰边缘。空间应具备合理的日常动线，明确分为入口生活区、工作区和睡眠区，不能让床与入口门相邻。

从左到右布置如下：最左侧是一扇大窗户；窗户右侧留出一段完整墙面，放置一扇浅木色入口门，门前必须有至少一个门宽的空地，不摆放床、书架或大型家具，可放一张矮鞋柜与小盆栽；入口门右侧隔开明显距离后，放置浅奶油色双门冰箱；冰箱右侧是柔软的浅鼠尾草绿色双人沙发，搭配两只蜜桃粉靠垫；画面中央保留一块宽敞干净的浅木地板活动区，作为水豚祁的主要活动空间；中右位置是带显示器、键盘、暖色台灯和小绿植的浅木质书桌；书桌右侧设置一组较高的开放式书架，作为工作区与睡眠区之间的轻隔断；最右侧是独立、安静的睡眠角，单人床靠最右侧连续墙面摆放，床头配一个小床头柜与暖色小灯，铺奶油色被子和浅绿色床单。床周围只保留床头柜与留白，不出现入口门，不被书架、门或通道挤压。

墙面为柔和奶白色，地面为浅木地板，少量绿植、靠垫、台灯和整洁生活小物点缀。室内无人，家具不被遮挡，不要悬浮菜单或其他界面元素。

### 前景

画面底部保留一张圆角柔软地毯的局部边缘，地毯位于沙发与中央活动区前方；前景仅增加极少量低矮物件，例如小盆栽、一本合上的书或靠垫，不能挡住中央活动区、书桌、床、冰箱和门。保留干净的浅木地板可视区域，前景层要轻、薄、易于后续叠加角色和互动特效。

### 共同限制

舒适、安静、治愈但不杂乱。入口门必须位于左侧入口生活区，门前留有空地；单人床必须位于最右侧独立睡眠角，床与入口门之间保持明显距离，并有书架或视觉留白作为分区。不要床紧贴入口门、不要门直接开向床、不要任何家具堵住门或主要通道。不要人物、动物、文字、标志、品牌、界面、水印、写实渲染、强对比、霓虹、像素画、3D、扁平矢量风、夸张广角或俯视镜头。输出干净静态背景；家具边缘清晰，中央区域留白充足，适合后续叠加角色、可点击热区与独立家具状态图层。
